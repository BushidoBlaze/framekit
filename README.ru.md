# FrameKit
 
[🇬🇧 English](README.md) | 🇷🇺 Русский
 
**Генерация структуры проекта под ваш стек технологий.**
 
FrameKit — расширение для VS Code, которое создаёт готовую структуру проекта в несколько кликов.
 
> ⚠️ **Проект в разработке.** Расширение активно разрабатывается и пока не опубликовано в Marketplace. Все перечисленные ниже возможности запланированы, если не отмечены как выполненные.
 
## Идея
 
Начало нового проекта обычно означает, что одни и те же папки и файлы приходится создавать снова и снова. FrameKit убирает эту рутину:
 
1. Запустите команду **FrameKit: Create Project** из палитры команд
2. Выберите технологию или стек (Node/TypeScript, Python, Go, ...)
3. Укажите папку, куда создать проект
4. Получите готовую структуру проекта
## Возможности
 
- [ ] Команда «FrameKit: Create Project»
- [ ] Выбор технологии через Quick Pick
- [ ] Встроенные шаблоны: Node/TypeScript, Python, Go
- [ ] Шаблоны хранятся как обычные папки и описания в JSON/YAML (расширять можно без знания TypeScript)
- [ ] Пользовательские шаблоны
- [ ] Переменные в шаблонах (название проекта, автор и т.д.)
## Планы развития
 
- **v0.1** — рабочий прототип: одна команда, три шаблона
- **v0.2** — больше стеков (FastAPI, Django, Go с `cmd/` и `internal/`, React и др.)
- **v0.3** — пользовательские шаблоны
- **Позже** — вынос ядра в отдельный пакет, CLI и поддержка других редакторов
## Установка
 
Пока недоступна. После публикации расширение можно будет установить из VS Code Marketplace, найдя его по названию **FrameKit**.
 
## Разработка
 
Требования: [Node.js](https://nodejs.org/) (LTS) и [VS Code](https://code.visualstudio.com/).
 
```bash
git clone https://github.com/ваш-ник/framekit.git
cd framekit
npm install
```
 
Откройте папку в VS Code и нажмите **F5**. Откроется новое окно (Extension Development Host) с загруженным расширением. Команды запускаются через палитру (`Ctrl+Shift+P`).
 
## Участие в проекте
 
Буду рад помощи, особенно с новыми шаблонами проектов для разных технологий. Чтобы добавить шаблон, знать TypeScript не нужно: шаблоны — это обычные файлы и описания.
 
- Нашли ошибку или есть идея? [Создайте issue](../../issues)
- Хотите добавить шаблон? Ищите задачи с метками `templates` или `good first issue`
